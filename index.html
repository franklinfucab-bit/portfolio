BinSense — Touchless Smart Waste Bin

ESP32-S3 · FreeRTOS · C++

A touchless waste bin built as a dual-core FreeRTOS application coordinating four sensors: PIR hand detection opens a stepper-driven lid, ultrasonic sensing tracks fill level, a photoresistor detects lid state, and temperature/humidity monitoring flags spoilage, with status on a 1602 LCD. Concurrent ultrasonic pulseIn() measurement was corrupting DHT11 bit-bang timing; interrupt locking fixed it. Self-calibration and closed-loop actuation confirmation use photoresistor feedback, documented with Doxygen.

5-Stage Pipelined LEGv8 Processor

SystemVerilog · UW EE 469

LEGv8 datapath · IF → ID → EX → MEM → WB

Designed and verified a 5-stage pipelined LEGv8 (ARM64 subset) CPU with full forwarding and hazard detection, passing all 12 benchmarks including recursive Fibonacci. The datapath was built incrementally — register file, ALU, single-cycle core, then pipeline — with each stage checked against predicted waveform traces.
